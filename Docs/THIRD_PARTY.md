# Third-Party & Asset Notes

## Unity Packages
- Universal Render Pipeline (Unity)
- UGUI / TextMeshPro (Unity)
- Input System (Unity)

## Runtime-generated content
This project deliberately generates terrain meshes, simple vegetation, icons, and ambient audio at runtime so the repository has **no missing binary asset references**.

## Recommended upgrades (optional)
When polishing for a public release, consider CC0 / appropriately licensed packs for:
- Tropical vegetation (e.g. Polyhaven, Kenney, CC0 terrain textures)
- Water shaders (URP community water)
- Ambient audio (Freesound CC0 wave/forest loops)

Always record attribution here when adding external assets.
